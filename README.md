# あの場所は今 ― イーグル隊長の空中散歩（ano-basho-flight） v1.5.0

行き先を入力すると、陽気な鷲「イーグル隊長」の足につかまって上空を飛び、
目的地に舞い降りて「昔と今」を音声で案内してくれる Web アプリです。

## ファイル構成

```
ano-basho-flight/
├─ index.html          画面（認証・搭乗券・フライト・到着）
├─ style.css           デザイン
├─ app.js              認証・フライト演出・音声・地図
├─ config.js           設定（GAS URL、3D地図・写真・映像・効果音）
├─ Code.gs             GAS バックエンド（認証・Gemini台本・Gemini TTS・履歴）
├─ .github/workflows/deploy.yml   Secrets から config.js を生成してデプロイ
└─ assets/             ※自分で用意（下記参照）
   ├─ video/ takeoff.mp4  cruise.mp4  dive.mp4
   └─ se/    eagle-cry.mp3  wind-loop.mp3  whoosh.mp3
```

## v1.5.0：AI音声（Gemini TTS）の回数を節約

Gemini TTS は無料枠だと「1モデルあたり1日100回」などの上限があり、超えると 429 エラーになります。

- **音声キャッシュ**：一度作ったセリフの音声を Drive の「ano-basho-flight 音声キャッシュ」に保存し、同じセリフは API を呼ばずに再利用（定番セリフ・「見る」・「もう一度飛ぶ」は2回目から0回）
- **解説をまとめて1回に**：到着後の解説（昔の面影〜締め）を1つの音声にまとめ、読んでいる段落の強調表示は再生位置から計算。「次へ」で次の段落へ移動
- **上限に達したとき**：GAS が「再試行までの時間」を覚えて、その間は API を呼ばずにすぐブラウザの声に切り替え（画面下に案内表示）
- 新しい場所への1フライトで使う AI 音声は約7回（離陸1・巡航3・急降下1・到着1・解説1）
- モデルを変えた直後などにすぐ AI 音声を試したいときは、エディタで `clearTtsQuotaBlock` を実行
- 音声キャッシュのフォルダは、容量が気になったら中身を削除してかまいません（次回作り直されます）

## v1.4.0：Maps APIキーをスクリプトプロパティへ移動

- Google Maps APIキーは config.js から削除し、GAS のスクリプトプロパティ `GOOGLE_MAPS_API_KEY` に設定します
- ログイン後、アプリが GAS（`mapsKey`）からキーを受け取って地図を表示します。GitHub のリポジトリにキーが残りません
- 地図はブラウザで表示する仕組みのため、キー自体はブラウザには届きます。不正利用の防止は、引き続き APIキーの **HTTP リファラー制限**（`https://kenken6291.github.io/*`）で行います
- GitHub Actions の Secrets `GOOGLE_MAPS_API_KEY` は不要になりました

## v1.3.0：思い出の場所の登録・表示・削除

ホーム画面を「思い出の場所」（登録したもの・件数制限なし）と「最近のフライト」（30件まで）に分けました。

- **登録**：到着画面の「思い出の場所に登録」、または一覧の「思い出の場所に登録」。「登録を外す」で最近のフライトに戻ります
- **表示**：「見る」で、飛ばずに到着画面（ストリートビュー・解説・写真）を開きます。音声は自動再生せず、下の「再生」で聞けます
- **削除**：記録を削除。その場所に写真がある場合は、写真も一緒に削除するか選べます（残した写真は同じ場所へ飛ぶとまた表示されます）
- 一覧には写真の枚数も表示されます
- `flights` シートに `id`・`saved` 列が追加されます（初回アクセス時に自動で見出しを追加。旧記録にも自動でIDを付けます）

**更新手順**：Code.gs を差し替えて保存 →「デプロイを管理」→ 鉛筆 →「新バージョン」で再デプロイ

## v1.2.0：思い出の写真を登録して見比べる

到着画面の下に「思い出の写真と見比べる」を追加しました。

- 写真はブラウザで長辺1600ピクセル・JPEG（約200〜500KB）に縮小してから送信。一覧用に長辺240ピクセルのサムネイルも作ります
- スマホの写真の向き（縦・横）は自動で補正
- 本体は Google ドライブの「ano-basho-flight 思い出の写真」フォルダに非公開で保存。表示は本人のログイン確認後に GAS 経由で読み出します
- サムネイルと説明は `photos` シートに保存
- 1か所あたり20枚まで、1日30枚まで（`DAILY_PHOTO_LIMIT` で変更可）
- 写真は「場所（緯度・経度）」ごとにまとまるので、同じ場所へもう一度飛ぶと前に登録した写真が出てきます
- 見比べ方は「並べて見る」と「重ねて見る」（写真の濃さを調整可能）。ストリートビューをドラッグして写真と同じ向きに合わせられます

**更新手順**
1. Code.gs を差し替えて保存
2. エディタで `setup` をもう一度実行 → Google ドライブの権限を承認（写真フォルダが作られます）
3. 「デプロイを管理」→ 鉛筆 →「新バージョン」で再デプロイ

## v1.1.0：現在地から思い出の場所まで 3D 地図で飛ぶ

Google Earth Studio は、ブラウザで手作業で映像を作って書き出すツールで、プログラムから呼び出す仕組み（API）がありません。
そのため「利用者ごとに現在地→思い出の場所」の映像をその場で作ることはできません。

そこで v1.1.0 では、Google Earth と同じ系統の立体写真地図（Photorealistic 3D 地図）を Maps JavaScript API で表示し、
カメラをリアルタイムに動かして飛ぶ方式にしました。

1. 離陸：現在地（位置情報。使えなければ config.js の出発地）の上空へ上昇
2. 待機：台本ができるまで出発地の上空を旋回
3. 巡航：高度を上げ、思い出の場所の方角を向いて上空を移動（距離に応じて高度と時間を自動調整）
4. 急降下：思い出の場所の真上へ降下
5. 着陸：近くのストリートビュー（50m → 250m → 1km の順に探す）にフェードで切り替え、到着のひと言
6. 到着画面：ストリートビューを最初に表示（写真がない場所は航空写真）

3D 地図が使えない環境（古い端末・WebGL 非対応・キー設定エラー）では、自動的に Earth Studio 映像モード（または空のアニメーション）で飛びます。

### 追加で必要な設定

- Google Cloud（キーと同じプロジェクト）で **Maps JavaScript API** を有効にする
- APIキーの「APIの制限」に **Maps JavaScript API** を追加（Maps Embed API はそのまま残す）
- Maps JavaScript API は請求先アカウントの設定が必要です。3D 地図・ストリートビューは無料枠を超えると課金されるので、
  Google Cloud の料金ページで最新の単価を確認し、「予算とアラート」で上限通知を設定しておくと安心です

## 処理の流れ

1. 「隊長と飛び立つ」を押す → GAS の `planFlight` が **Geocoder で住所・座標を確定** → Gemini（Google検索グラウンディング付き）が隊長の台本 JSON を生成
2. 台本を待つ間も演出は止めない：定番の離陸セリフ・つなぎの雑談（アプリ内蔵）を先に TTS で再生
3. 台本が届いたら巡航中の実況 → 急降下 → 到着
4. 到着画面：ストリートビュー／航空写真／地図 ＋ 「昔の面影・今の姿・ここが変わったぜ・豆知識」を順番に読み上げ
5. 台本は `flights` シートに保存。「これまでのフライト」から **Gemini を呼ばずに** もう一度飛べる

## セットアップ手順

### 1. スプレッドシートと GAS

1. Google スプレッドシートを新規作成（名前は自由）
2. 拡張機能 → Apps Script → `Code.gs` の中身を貼り付けて保存
3. プロジェクトの設定 → スクリプト プロパティに追加
   | キー | 値 |
   |---|---|
   | `GEMINI_API_KEY` | Gemini API キー（必須） |
   | `GOOGLE_MAPS_API_KEY` | Google Maps API キー（必須。リファラー制限を付けたもの） |
   | `APP_URL` | `https://kenken6291.github.io/ano-basho-flight/` |
   | `GEMINI_MODEL` | 任意（既定 `gemini-2.5-flash`） |
   | `GEMINI_TTS_MODEL` | 任意（既定 `gemini-2.5-flash-preview-tts`）※普段使っているTTSモデル名に合わせてください |
   | `TTS_VOICE` | 任意（既定 `Puck`） |
   | `USE_SEARCH` | 任意（既定 `true`） |
4. エディタで `setup` を実行 → 権限を承認（スプレッドシート・メール・Maps・外部通信）
   - `members` / `flights` シートと `PEPPER` が自動で作られます（**PEPPER は後から変えない**。変えると全員ログイン不可）
5. `testScript` と `testTts` を実行して、ログに台本と音声データ長が出ることを確認
6. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」
   - 実行するユーザー：**自分**
   - アクセスできるユーザー：**全員**
   - 表示された `…/exec` の URL を控える

> ⚠️ **Code.gs を変更したら、必ず「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」で再デプロイ。**
> 保存しただけでは公開中の /exec に反映されません。フッターの「サーバー v○○」で反映を確認できます。

### 2. Google Maps API キー（スクリプトプロパティ `GOOGLE_MAPS_API_KEY` に設定）

- Google Cloud Console で **Maps Embed API** を有効化してキーを作成
- アプリケーションの制限：HTTP リファラー `https://kenken6291.github.io/*`
- API の制限：Maps Embed API のみ
- Embed API は無料枠の上限なしで使えます。キー未設定でも航空写真・地図は表示され、ストリートビューは Google マップへのリンクになります
- streetview-reunion3 で使っているキーに Embed API を追加して使い回すこともできます

### 3. GitHub Pages

1. リポジトリ `ano-basho-flight` を作成し、全ファイルを push
2. Settings → Pages → Source を **GitHub Actions** に
3. Settings → Secrets and variables → Actions に追加
   - `GAS_API_URL` … GAS の `/exec` URL
4. push すると `deploy.yml` が config.js のプレースホルダーを置き換えて公開

Actions を使わない場合は config.js の `__GAS_API_URL__` などを直接書き換えて push してください。

### 4. バージョン更新

- 画面側：`config.js` の `APP_VERSION`
- サーバー側：`Code.gs` の `APP_VERSION`（＋新バージョンで再デプロイ）
- フッターに両方表示されるので、食い違いがあればデプロイ漏れです

## Gemini プロンプト設計

### 台本生成（`Code.gs` の `EAGLE_SYSTEM_PROMPT` / `buildUserPrompt_`）

キャラクターと事実ルールをシステムプロンプトに、行き先・住所・座標・時期・思い出メモをユーザープロンプトに分けています。

| 設計ポイント | ねらい |
|---|---|
| 一人称「オレ」、相棒呼び、語尾「〜だぜ」 | キャラの一貫性。べらんめえ過ぎないよう「品よく陽気に」と明記 |
| 1文40字以内・横文字を避ける | 読み上げで聞き取りやすく、テロップも2行に収まる |
| 確かでないことはぼかす／実在しない店名を作らない | 「あの場所は今」は事実誤認が一番の興ざめ。検索で確認できた固有名詞だけ使わせる |
| 思い出メモを最優先・否定しない | 利用者の記憶が主役。AIの知識より優先 |
| 災害・事故は茶化さない | お調子者キャラでも越えない一線 |
| 出力を JSON のキー固定に | 演出の各フェーズにそのまま流し込める |

出力 JSON：`placeName / cruise[3] / dive / arrival / then / now / gap / trivia / closing`

- Google 検索グラウンディングと JSON モードは同時に使えないため、検索ありで JSON が崩れたときは検索なし（JSON モード）で自動再試行します
- 参照した Web ページは到着画面の「隊長が参考にした情報」に表示されます
- 口調を変えたいときは `EAGLE_SYSTEM_PROMPT` の【キャラクター】だけを編集すれば OK です

### 音声（Gemini TTS）

- `TTS_STYLE` プロパティで読み方を指示（既定：陽気で自信たっぷり、少し早口）
- 声の候補：`Puck`（明るい）、`Fenrir`（勢い）、`Charon`（渋い）、`Orus`（しっかり）など。`testTts` で聞き比べてください
- Gemini TTS は PCM（24kHz）を返すため、app.js で WAV ヘッダーを付けて再生しています
- TTS が失敗したときはブラウザの読み上げ（Web Speech API）で自動代用します

## Google Earth Studio 映像の作り方

Earth Studio は自動生成の API がないため、**どの行き先にも使える汎用クリップを3本**作り、AIの実況で「その場所らしさ」を出す構成にしています。
特定の場所用の専用映像を作った場合は config.js の `SPECIAL_FLIGHTS` に登録すると、行き先に含まれる言葉で自動的に差し替わります。

| クリップ | 長さ | 作り方の例 |
|---|---|---|
| takeoff.mp4（離陸） | 4〜6秒 | 山の稜線や崖の上、高度20〜30mから開始 → 800mまで上昇しつつカメラを前傾から水平へ |
| cruise.mp4（巡航・ループ） | 20〜30秒 | テンプレート「Orbit」で富士山や田園地帯を高度3,000〜5,000mから360°周回。始点と終点が一致するので継ぎ目なくループできる |
| dive.mp4（急降下） | 4〜6秒 | 住宅街の上空 2,000m → 150m へ一気に降下、カメラのチルトを下向きに。特定の街に見えない住宅地を選ぶと、どの行き先にも合う |

**推奨設定**
- 解像度：1280×720（軽さ重視）または 1920×1080、30fps
- イージングをかけると「つかまっている感」が出ます（離陸は加速、急降下は終盤で減速）
- 映像内の Google Earth の帰属表示は消さないこと（Earth Studio の利用ガイドラインに従ってください）。アプリ側でも画面右下に表示しています

**動画化（Earth Studio は連番 JPEG で書き出されます）**

```bash
ffmpeg -framerate 30 -i takeoff_%03d.jpeg -vf "scale=1280:-2" \
  -c:v libx264 -preset slow -crf 26 -pix_fmt yuv420p -movflags +faststart -an takeoff.mp4
```

`-movflags +faststart` を付けると読み込み途中から再生が始まります。1本 5〜15MB 程度が目安です。

## 映像・効果音の置き場所（GitHub と Google Drive）

config.js の各アセットは `url` を優先し、読み込めなければ `driveId` を試し、それもダメなら CSS の空と雲のアニメーションで代用します。

```js
takeoff: { url: 'assets/video/takeoff.mp4', driveId: '1AbC...xyz' }
```

**おすすめ：リポジトリの `assets/` に置く（url）**
GitHub Pages は CDN 配信なので安定して速いです（1ファイル100MB未満）。

**Google Drive に置く場合（driveId）**
1. ファイルを Drive にアップロード → 共有 →「リンクを知っている全員（閲覧者）」
2. 共有リンク `https://drive.google.com/file/d/【ここがID】/view` の ID を `driveId` に設定
3. 注意点
   - Drive は動画配信用ではないため、再生開始が遅い・アクセスが集中すると一時的に再生できなくなることがあります
   - 約100MBを超えるとウイルススキャン確認画面が挟まり、ブラウザで直接再生できません
   - そのため Drive は「予備」または小さめのファイル向けと考えるのが無難です

**効果音**
- `eagle-cry.mp3`（鷲の鳴き声）、`wind-loop.mp3`（風切り音・ループ用）、`whoosh.mp3`（急降下）
- 効果音ラボなど、利用規約でWeb利用が認められている素材を使ってください
- 効果音が無くても動作します（無音でスキップ）

## 会員機能まとめ

- 新規登録：ニックネーム＋メール → 仮パスワードをメール送信
- 初回ログイン：パスワード変更画面へ強制遷移（8文字以上・英字＋数字）
- パスワード忘れ：仮パスワード再発行（登録有無は画面で区別しない）
- パスワード欄の表示／非表示切替（目のアイコン）
- 5回連続失敗で15分ロック
- パスワードは SHA-256＋salt＋pepper（500回ストレッチ）で保存
- セッションは CacheService（6時間、利用のたびに延長）、トークンは localStorage

## 利用制限

- フライト（台本生成）：1人1日20回（`DAILY_FLIGHT_LIMIT`）
- 音声生成：1人1日300回（`DAILY_TTS_LIMIT`）
- カウントは CacheService のため「おおよそ1日」です（最大6時間で自然リセットされることがあります）

## 既知の制約

- AI の「昔の面影」は推測を含みます。画面に注意書きを表示しています
- ストリートビューは撮影されていない場所では灰色になります。その場合は「航空写真」タブへ
- iPhone はマナーモード中だと音が出ないことがあります
